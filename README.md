# Insurance-cost-analysis
## Project Overview
An Exploratory Data Analysis (EDA) project focused on understanding the factors influencing medical insurance charges using Python.

## Business Problem
Insurance companies need to understand how customer characteristics influence medical insurance costs. This project explores relationships between customer demographics, health indicators, and insurance charges.

## Objectives
- Analyze customer demographics and insurance charges.
- Identify factors associated with higher insurance costs.
- Explore the relationship between age, BMI, smoking status, and charges.
- Identify potential outliers.
- Perform feature engineering using BMI categories and age groups.
- Generate business insights through data visualization.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset
Insurance dataset containing:
- Age
- Sex
- BMI
- Children
- Smoker
- Region
- Charges

## Project Workflow
1. Data Loading and Inspection
2. Data Quality Assessment
3. Exploratory Data Analysis
4. Univariate Analysis
5. Bivariate Analysis
6. Multivariate Analysis
7. Outlier Exploration
8. Feature Engineering
9. Group-wise Analysis
10. Business Insights

## Key Insights
- Smoking status is strongly associated with insurance charges.
- Insurance charges generally increase with age.
- BMI is another factor associated with insurance costs.
- Insurance charges vary across customer groups.

## Conclusion
This project demonstrates practical data analysis skills, including data cleaning, exploratory analysis, feature engineering, and visualization.
